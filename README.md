# 🌐 Trace a Packet End-to-End

A complete hands-on networking lab that traces an application request through **DNS Resolution, Routing, ARP/Neighbor Discovery, TCP Handshake, HTTP/HTTPS Traffic**, and **Wireshark PCAP Analysis**.

---

## 📌 Project Overview

This repository demonstrates the step-by-step flow of network traffic from a local Linux host to a remote destination (`example.com`).
